Hook cleanup:

{{- if .Values.github.webhook.deleteHookOnFinish }}
  github.webhook.deleteHookOnFinish is on. The event source deletes the hooks
  it registered when it stops, so a repository removed from repositories loses
  its webhook on the next restart. A crash can leave a hook behind.
{{- else }}
  github.webhook.deleteHookOnFinish is off. The event source leaves its hooks
  in place. A crash can leave a hook behind.
{{- end }}

  The option applies only when the chart registers hooks, which needs
  github.apiTokenSecret or github.githubApp with github.webhook.url.
